C29x Academy

The C29x Academy is a great resource for developers to learn about C29x-based C2000 real-time microcontrollers platform. The Academy delivers easy-to-use training modules that span a wide range of topics for C29x devices. C29x Academy is applicable to generation-4 devices- F29H85x, F29P58x, F29P32x

Overview of C29x CPU Architecture and Accelerators

3. System#

Texas Instruments

GPIOs

This module describes General Purpose Input Output (GPIO) pins. GPIOs are the digital signals used as inputs and outputs of the device.

Texas Instruments

Crossbars (X-BAR)

This module describes the Crossbar modules on C29x devices. Crossbars provide the ability to route different signals throughout the device.

Texas Instruments

Interrupts

An interrupt is a response by the processor/CPU to an event that needs attention. This module goes over C29x interrupt architecure, how to setup interrupts, the types of interrupts there are, and how the Peripheral Interrupt Priority Expander (PIPE) module is used on C29x devices.

Texas Instruments

Timers

This module describes C29x CPU Timers and the watchdog timer which is a safety feature that will reset the device if something goes astray in the system.

Texas Instruments

Error Handling

This module describes the Error Aggregator (EA) and Error Signaling Module (ESM) on C29x devices. The ESM provides a systematic consolidation of responses to error events throughout the device into one location.

Texas Instruments

Flash Memory

This module describes the structure of C29x device Flash memory, the proper sequence to initialize and configure Flash, and how to improve Flash performance.

Texas Instruments

External Memory Interface (EMIF)

When an application requires more memory than what is available on-chip, the EMIF controller can be used to connect to external memory devices. This module gives an introduction to the EMIF.

4. Analog Subsystem#

Texas Instruments

Analog to Digital Converter (ADC)

C2000 devices support multiple analog-to-digital converters (ADCs). This module describes the different components in the ADC and how to setup the ADC.

Texas Instruments

Comparator Subsystem (CMPSS)

Each Comparator Subsystem (CMPSS) has two comparators within it. This module describes how the comparators can be used and setup.

Texas Instruments

Digital to Analog Converter (DAC)

The buffered DAC can be used to provide a programmable reference output voltage. This modules walks though the DAC features and the DAC block diagram.

Texas Instruments

Analog Subsystem

The analog subsystem connects the ADC, CMPSS, and DAC modules. This allows a single pin to route a signal to multiple analog modules and highly flexible pin usage, allowing for smaller device packages.

5. Control Peripherals#

Texas Instruments

Enhanced Pulse Width Modulation (EPWM)

The C2000 high-performance control peripherals are an integral component for all digital control systems. This module will cover pulse width modulation (PWM).

Texas Instruments

Enhanced Capture Module (ECAP)

The C2000 enhanced capture (ECAP) module allows time-based logging of external signal transitions. It is used to accurately time external events by time stamping transitions on the capture input pin.

Texas Instruments

Enhanced Quadrature Encoder Pulse (EQEP)

The Enhanced Quadrature Encoder Pulse (EQEP) module is essential when integrating C2000 devices in any application that requires motor control. The EQEP module enables the C2000 device to interact with linear or rotary incremental encoders to determine necessary motor information from rotating machines.

Texas Instruments

Sigma-Delta Filter Module (SDFM)

The C2000 Sigma Delta Filter Module (SDFM) is a four-channel digital filter designed specifically for current measurement in motor control applications.

6. Communication Peripherals#

Texas Instruments

Communications Overview

C2000 devices contain features that allow several methods of communication and data exchange between the MCU and other devices. Many of the most commonly used communications techniques are presented in this module.

Texas Instruments

Fast Serial Interface (FSI)

The FSI module is a highly reliable high-speed serial communication peripheral capable of operating at dual data rate, providing 100 Mbps transfer using a 50 MHz clock.

Texas Instruments

Inter-Integrated Circuit (I2C)

The I2C provides an interface between devices that connect using an I2C-bus and are compliant with I2C-bus specification version 2.1.

Texas Instruments

Universal Asynchronous Receiver Transmitter (UART)

The UART communication module provides a communication interface between devices by performing the functions of parallel-to-serial and serial-to-parallel conversions. This module covers the basics of UART communciation, data flow, and common applications.

Texas Instruments

Serial Peripheral Interface (SPI)

The SPI is a high-speed synchronous serial port that shifts a programmable length serial bit stream into and out of the device at a programmable bit-transfer rate.

Texas Instruments

Controller Area Network (CAN)

CAN is a serial communications protocol which efficiently supports distributed real-time control with a high level of reliability.

Texas Instruments

CAN Flexible Data Rate (CAN FD/MCAN)

CAN FD refers to the protocol while MCAN refers to the physical module on the device that implements the CAN FD protocol.

Texas Instruments

Local Interconnect Network (LIN)

The LIN standard is based on the SCI (UART) serial data link format. The communication concept is single-commander/multiple-responder with a message identification for multi-cast transmission between any network nodes.

Texas Instruments

Power Management Bus (PMBus)

The PMBus module provides an interface for communicating between the microcontroller and other devices that are compliant with the System Management Interface (SMI) specification.

Texas Instruments

Ethernet for Control Automation Technology (EtherCAT)

Ethernet for Control Automation Technology (EtherCAT®) is an Ethernet-based field bus system.

Texas Instruments

Single Edge Nibble Transmission (SENT)

The SENT module provides an interface for communicating between a microcontroller and other devices. This protocol on C29x devices was based on the open standard SAE J2716 with additional enhancements such as additional sensor format support.

7. Security and Safety Peripherals#

Texas Instruments

Safety Security Unit (SSU)

This module describes the features and operation of the Safety and Security Unit (SSU). The SSU is the central element of the C29x security architecture. It provides run-time safety and security for the application CPU subsystems, and governs debug access to various resources on the chip.

Texas Instruments

Hardware Security Module (HSM)

The HSM is a self-contained subsystem within the device that provides security and cryptographic functions. The host C29 subsystem interfaces with the HSM subsystem to perform the cryptographic operations required for code authentication, secure boot, secure firmware upgrades and encrypted run-time communications.

8. Debug and Diagnostics#

Texas Instruments

Embedded Real-time Analysis and Diagnostic (ERAD)

The ERAD module of C29x devices enhances the debug and system analysis capabilities of the device. This module facilitates sophisticated non-intrusive detection and monitoring of the CPU operation in real-time.

Texas Instruments

Data Log and Trace (DLT)

The DLT makes it possible to collect, time-stamp, pre-filter, export, and do real-time and post analysis of data. When data-logging, the DLT is non-intrusive meaning there is no impact to run-time or CPU core behavior.

Texas Instruments

Waveform Analyzer Diagnostic (WADI)

The waveform analyzer and diagnostic (WADI) peripheral consists of many useful built in signal analysis support and provides a safety mechanism for the signals. This module provides a foundational understanding of the WADI.

Texas Instruments

Embedded Pulse Generator (EPG)

The Embedded Pattern Generator (EPG) module is a customizable pattern and clock generator that could serve many test and application scenarios that require a simple pattern generator or a periodic clock generator. The EPG module can also be used to capture an incoming serial stream of data.

Texas Instruments

C29 Debugging Tips

This module describes various topics related to debugging issues on the C29-based family of devices.

9. Advanced Topics#

Texas Instruments

Real-Time Direct Memory Access (RTDMA)

On C29x devices, RTDMA module provides a hardware method of transferring data between peripherals and/or memory without intervention from the CPU to effectively free up the CPU for other functions.

Texas Instruments

Configurable Logic Block (CLB)

The Configurable Logic Block (CLB) is a peripheral exclusive to C2000 devices that allows users to incorporate custom logic without the need for an external logic device such as an FPGA or CLPD.

Texas Instruments

Interprocessor Communications (IPC)

IPC allows communication between two CPU subsystems (ex. CPU1 and CPU2). This module explains the use and operation of IPC.

Lab Exercises#

Texas Instruments

Timer LED Lab

START HERE! Begin your hands-on experience by completing this introductory lab exercise. This lab walks through simple project development steps within CCS, utilizes the built-in SysConfig GUI, and ultimately demonstrates how to use a CPU Timer interrupt to blink two LEDs on your board.

Texas Instruments

RTDMA Lab

Use the RTDMA module along with the ADC in a real-time data processing application. An EPWM waveform will be used to simulate a real-time data signal, and the ADC will sample this waveform at a specified rate. The RTDMA will be used to store ADC samples in a ping pong buffer so groups of samples can be processed by the CPU in an ISR.

Texas Instruments

EPWM and ECAP Lab

Generate a basic PWM waveform using one of the EPWM modules. The period and duty cycle of the PWM waveform will be measured by one of the ECAP modules.

Texas Instruments

EQEP Lab

Explore a common use-case of the EQEP module by connecting quadrature signals to your device. This lab uses the EQEP to calculate motor characteristics.

Texas Instruments

UART Lab

Use the UART module to send and receive data between a C29 device and a computer. The computer will be used to change the frequency of a blinking LED, and the board will echo the corresponding value back to the computer.

Texas Instruments

FSI Lab

Use the FSI module to send and receive data using the internal loopback feature. The FSI ping frame feature will be used to validate communication between the FSI receiver module and FSI transmitter module.

Texas Instruments

CLB Lab

Use CLB module and its submodules to connect to other peripherals of the device, perform logical operations, override peripheral outputs, and then generate interrupts to the CPU.

Texas Instruments

CLB and ECAP Lab

Use the CLB to connect to a signal, accurately time events, and send data to the CPU. The CLB will measure a high signal, a low signal, and another high signal before sending the data to the CPU. An ePWM module will be set up to supply a signal if a wave generator is not available.

Texas Instruments

System Integration Lab

Use the GPIO, EPWM, ADC, DAC, CMPSS, and ESM modules in this comprehensive example. In this system, the ePWM module generates a PWM waveform with a duty cycle that varies based on an ADC conversion result. A comparator will also be used to monitor the ADC conversion results and cause a one-shot trip to drive the ePWM output low when the ADC conversion is above a certain threshold.The ESM is also configured to drive the error status pin in response.

Texas Instruments

MCAL EPWM Lab

Get familiar with F29x Microcontroller Abstraction Layer (MCAL) configuration in this EPWM MCAL demo! We will set up four EPWM instances using the tool EB Tresos in order to perform PWM phase shifting.
